About Archive Viewer

Version 1.5 (message keyword and calendar date filtering, manual quoted-reply linking). This is a local-first viewer for WhatsApp text exports and ZIP archives. It reconstructs message bubbles and displays media files included in the export. It is not WhatsApp and cannot restore an archive into WhatsApp.

Privacy: files are processed in your browser. This starter uses JSZip from a public CDN to read ZIP files; no archive upload endpoint is configured.

Known limitations: Android export formats vary by language and WhatsApp version. Reactions, delivery/read receipts, disappearing-message state, exact reply relationships and some system events may not be represented in the text export. Reply links you create are stored locally in this browser, not in the WhatsApp file.
